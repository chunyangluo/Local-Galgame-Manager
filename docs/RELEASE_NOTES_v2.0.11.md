## Local Galgame Manager v2.0.11

- **自动化解压工具**：监控目录扫描、解压、整理到游戏库（进度条、可停止、彩色日志）
- **HBE 解密**：Hexo Blog Encrypt 离线 HTML 单文件/批量解密
- **插件系统 v1**：扫描/启动钩子、插件包、示例与脚手架
- **数据管理**：库内列表删除、可选删除安装目录

- 「更多」菜单按场景重组

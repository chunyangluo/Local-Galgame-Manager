# 用户使用手册（V2.0 VNDB-Only）

## 启动
- 安装依赖：`pip install -r requirements.txt`
- 启动程序：`python -m app.main`

## 核心流程
1. 点击“添加扫描目录”，选择你的游戏根目录。
2. 点击“全量扫描”，先识别本地可启动游戏，再自动执行 **VNDB 批量导入**（6 线程）。
3. 导入结束后会弹出结果窗口，显示成功/失败统计及失败原因。
4. 选中游戏后点击“启动游戏”或“管理员启动”。

## VNDB 批量导入（无鉴权模式）
- 顶部工具栏提供 `VNDB 批量导入` 按钮，可对当前库内游戏再次匹配 VNDB 数据。
- 导入后会写入：
  - 标题（原文/本地化）
  - 简介、评分、平台、语言
  - VNDB 主封面 URL、截图 URL 列表
- 封面渲染策略：
  - 优先使用已缓存的 VNDB 封面
  - 缓存缺失时可直接使用 VNDB CDN URL 加载

## VNDB 失败原因说明
- `timeout`：请求超时（网络波动或目标响应慢）
- `no_match`：VNDB 没有匹配到条目
- `http_error`：接口返回 HTTP 错误
- `parse_error`：接口返回内容结构异常
- `rate_limit`：触发公共接口限流
- `network_error`：本地网络不可用或连接中断

## 常用功能
- **修正启动EXE**：为识别错误的游戏手工指定主程序。
- **收藏/取消收藏**：快速维护常玩列表。
- **新建分类 / 分配分类**：支持一个游戏归属多个分类（逗号分隔）。
- **设置封面**：导入本地图片自动适配卡片比例。
- **创建桌面快捷方式**：为选中游戏创建桌面入口。

## 数据安全
- 点击“导出备份”可打包数据库快照。
- 点击“恢复备份”可恢复到某个历史快照。

## 运行与限流建议（VNDB Public No-Auth）
- 当前默认 6 线程并发导入，适合 50~200 条批量任务。
- VNDB 公共无鉴权接口有请求频率限制；大量导入时可能出现短时 `rate_limit`。
- 建议在网络稳定时导入，失败条目可直接再次执行“VNDB 批量导入”重试。
- 程序已内置超时与退避重试，避免长时间卡死 UI。

## 多用户
- 右上角下拉框切换本地用户。
- “新建用户”会创建独立收藏、分类和游玩记录空间。
